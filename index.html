Rapports de dépenses

01

Quel formulaire devez-vous remplir?

Répondez à quelques questions pour trouver le formulaire adapté à votre demande.

QUESTION 1

Votre demande concerne-t-elle des achats ou un déplacement lié au travail?

Par exemple, des fournitures (incluant achats pour le fonds d'aide aux élèves dans le besoin), du matériel, les achats des délégués ou un déplacement professionnel?

02

Accès direct aux formulaires

Vous savez déjà quel formulaire utiliser? Sélectionnez-le directement!

FORMULAIRE A

Rapport de déplacements

Pour un déplacement d'au moins deux jours comprenant un coucher.

Ce formulaire peut inclure :

  • Les frais de transport
  • Les repas
  • Les dépenses diverses
Accéder au formulaire
FORMULAIRE B

Rapport de déplacements

Pour un déplacement avec aller-retour dans la même journée, sans coucher.

Ce formulaire peut inclure :

  • Les frais de transport
  • Les repas
  • Les dépenses diverses
Accéder au formulaire
FORMULAIRE C

Remboursement des achats

Pour des achats effectués, sans déplacement à déclarer.

Par exemple :

  • Fournitures de bureau
  • Achats par les délégués
  • Fonds d'aide aux élèves dans le besoin
